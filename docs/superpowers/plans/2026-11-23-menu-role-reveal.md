# Main Menu, Role Reveal & Return-to-Menu Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a Menu scene (Chơi / Hướng dẫn / Thoát), a role-reveal card before the head-start, and make the end/pause screens return to the Menu, with the flow `Loading (once) → Menu → Game`.

**Architecture:** A new `MatchPhase.RoleReveal` in `MatchController` runs before `HeadStart` and locks both teams; `MatchHudView` renders the card. Scene names live in one static class; `MatchController.ReturnToMenu()` replaces `Quit()`. The Menu scene and the HUD card are generated by an idempotent Editor setup tool (same pattern as `Assets/Editor/MapCollisionSetup.cs`), run once in the open Editor.

**Tech Stack:** Unity 6000.0.72f1, uGUI (`UnityEngine.UI.Text`/`Button`, built-in LegacyRuntime font), DOTween, VContainer, NUnit EditMode tests.

**Spec:** `docs/superpowers/specs/2026-11-23-menu-role-reveal-design.md`

## Global Constraints

- Build Settings order: `Assets/Scenes/Loading.unity` (0) → `Assets/Scenes/Menu.unity` (1) → `Assets/Scenes/Game.unity` (2).
- Loading runs only at app start; Menu → Game loads `Game` directly; Replay reloads `Game`.
- Every scene exit from the match resets `Time.timeScale = 1f` **before** loading.
- Role reveal default duration `2.5f` seconds, Inspector-configurable, `0` skips it; no tap-to-skip.
- During role reveal: Chasers **and** Runners have `IsActionLocked = true`; head-start timer does not decrease; main clock does not decrease.
- Card copy (exact): Chaser → title `BẠN LÀ GÀ`, subtitle `Bắt hết phe Người trước khi hết giờ!`; Runner → title `BẠN LÀ NGƯỜI`, subtitle `Trốn đến hết giờ!`.
- End-screen and pause-menu "Thoát" buttons become `Về Menu`. Only the Menu scene has an app-quit button (`Thoát`).
- Do not rename existing `[SerializeField]` fields (`quitButton`, `pauseQuitButton`) — scene references depend on them.
- Non-goals: Settings screen, choosing a side, 8-slot lobby, audio, items, Android Back button.
- Verify C# with `dotnet build` (Editor stays open; batch mode is usually blocked).

## Review Focus

1. Pausing during role reveal → reveal timer freezes; resuming continues it (test in Task 3).
2. Pressing "Chơi lại"/"Về Menu" from the pause menu while frozen → next scene runs at `timeScale 1` (test in Task 1 via `PrepareSceneExit`).
3. Characters spawned after the first `Step` (spawn race) → still get locked for the reveal once they appear (test in Task 3).
4. Role reveal → head-start transition → Runners unlocked, Chasers stay locked (test in Task 3).
5. Menu → Game → Menu → Game twice → no frozen clock, no leftover HUD tweens (manual check in Task 5).

### Task 3: `RoleReveal` match phase

**Files:**
- Modify: `Assets/Scripts/Match/MatchState.cs` (`enum MatchPhase { RoleReveal, HeadStart, Playing, Ended }`), `Assets/Scripts/Match/MatchController.cs`
- Test: `Assets/Tests/EditMode/MatchControllerTests.cs`

**Interfaces:**
- Consumes: `MatchHudView.RenderRoleReveal(bool active, Team playerTeam)` from Task 2 (call via `hud?.`).
- Produces: `[SerializeField] float roleRevealDurationSeconds = 2.5f;` with property `public float RoleRevealDurationSeconds { get; set; }` (setter clamps ≥ 0), `public float RoleRevealRemaining { get; }`.
- Produces: `public static void SetAllLocked(ITeamRoster teamRoster, bool locked)` — sets `IsActionLocked` on every Chaser and Runner.

Behaviour: `InitializeMatch()` sets `roleRevealRemaining = max(0, roleRevealDurationSeconds)` and `phase = RoleReveal` if > 0, else `HeadStart` if head-start > 0, else `Playing`. Initial locks: `RoleReveal` → `SetAllLocked(true)`; otherwise the existing `SetHeadStartChaserLock`. The "apply initial locks once characters exist" gate stays. The `RoleReveal` branch sits after the `isPaused` check, decrements `roleRevealRemaining`, renders the card + clock, returns; when it reaches 0: `phase = HeadStart` (or `Playing` + ready-banner path if head-start is 0), `SetAllLocked(false)` then `SetHeadStartChaserLock(roster, true)` when entering `HeadStart`, hide card. Leftover delta is not carried into head-start.
